# ことばのわざ概念ツリー

小学校国語「読むこと」の教材研究のための、教師用の Web アプリです。
説明的な文章・文学的な文章を読むときに働く「わざ」（概念）を、学習指導要領の構成に沿ってツリーと星図で整理し、わざどうしのつながりを示します。

**アプリを開く**: `index.html` をブラウザで開くだけで動きます（GitHub Pages で公開した場合はそのページ）。インストールやサーバーは要りません。

GitHub Pages のページを Chrome・Edge で開くと、アドレスバーのインストールボタンからアプリとして入れられます（iPad・iPhone は Safari の共有 →「ホーム画面に追加」）。一度開けば、通信できないときも使えます。

## できること

- **2つの領域**：説明的な文章／文学的な文章 を切り替えて見る
- **わざのツリー**：学習指導要領の指導事項に由来する所属（銀河・星雲）で、204 のわざ（まとめの枠を含めると 252 項目）を整理
  - ことばのわざ：〔知識及び技能〕⑴〜⑶ に由来する、両領域で共有するわざ
  - そうさのわざ：線・囲み・矢印・番号など、本文に書き込む単純な操作
- **つながり**：327 本のエッジ（手がかり／主題へ／要旨へ／比べる／効果／関わり）
- **ことばのわざ宇宙**：わざとつながりを、ことば・そうさ・説明・文学の4つの銀河の3D空間として見る別画面。左の「ことばのわざ宇宙へ」から、いま開いているデータで別の窓に開きます。宇宙の画面は index.html に入っているので、index.html 1つでもオフラインで使えます
- **系統・根拠**：各わざに、学習指導要領解説の該当箇所と参考文献を表示
- **教材を選ぶ・探究のぶき**：教材や学年に合わせて、使うわざを絞り込んで見る
- **指導計画ファイルを作るプロンプト**：教科書会社の年間指導計画から、生成AIで .sdkk を作るためのプロンプト（[prompts/shidou_keikaku_prompt.md](prompts/shidou_keikaku_prompt.md)）。アプリの「リストを書き出す／読み込む」からもダウンロードできます
- **教材データの読み込み**：`.sdkk` 形式の教材データ（ネットワークで .sdkk がはじかれるときは、中身が同じ `.txt`・CSV、または Google スプレッドシートなどへの貼り付けでも運べます）を読み込むと、その教材の単元配置に合わせて表示（データはブラウザ内にだけ保存）

## データの扱い

- アプリに入っているのは、公開できる本体データ（`data/core_data.json`）だけです。
- 教科書会社の資料に基づく教材データは含めていません（`.gitignore` で除外）。
- 学年帯・教材との対応・効果の付け方は、いずれも要確認の叩き台です。

## ファイル構成

```
index.html              アプリ本体（データ埋め込み済み・単体で動く）
src/app_template.html   アプリのテンプレート
src/uchu_template.html  概念宇宙のテンプレート
data/core_data.json     わざ・つながり・根拠の本体データ
build.py                テンプレートにデータと宇宙の画面を埋め込んで index.html を作る
manifest.webmanifest    アプリとしてインストールするための設定（PWA）
sw.js                   オフラインでも開けるようにする仕組み
icons/                  アプリのアイコン
prompts/                生成AIに渡すプロンプト（指導計画ファイル作成用）
SOURCES.md              出典
LICENSE                 コードのライセンス（MIT）
LICENSE-DATA.md         データのライセンス（CC BY-SA 4.0）
```

## 作り直し方

`data/core_data.json` または `src/` のテンプレートを直したら、次を実行します（Python 3、追加ライブラリ不要）。

```
python3 build.py
```
